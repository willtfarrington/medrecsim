# Risk register

Consolidated from the four specialist workstreams plus integration-level risks. Owner = who
watches for the trigger. Review this register at the two re-plan checkpoints (post-EP-19,
post-EP-35) and at every release.

Evidence that would **narrow, redesign, defer, or stop** work (charter domain 16): a credible
fairness challenge pattern (≥2 sustained freezes) → pause case wave, redesign the affected
action-set authoring process; SP-7 failure → redesign debrief; owner review stalling ≥ one
release cycle → shrink roster / recruit reviewer / pause R2; any restricted-data or PHI near-miss
→ stop, run incident procedure, re-audit the leak-prevention stack before resuming.
