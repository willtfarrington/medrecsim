## Decisions logged (reversible technical, D-EXEC-003)

- **Schema 0.1 stays 0.1** despite additive universe fields (`locality`, `identifiers`,
  `screening`, `shortName`, `institutionId`): ADR-7 dates the "additive = minor bump" rule
  from the first reviewed case (EP-14); before that, additive pre-exemplar changes re-export
  the JSON Schema without a re-stamp. Recorded so EP-14 knows the rule starts there.
- **Screening is an invariant, not a schema requirement** (`screening` optional in Zod,
  required by `INV-SCOPE-001` unless `placeholder: true`), keeping the exported JSON Schema
  simple and the error attributed by name.
- **Prose scan scope**: ten-digit phone forms and `NPI`-labelled ten-digit numbers only;
  seven-digit numbers are not scanned (dose/quantity false positives). Authors write phone
  numbers as the local part `555-01XX`.
- **NPI convention = leading 0 AND invalid check digit** (two independent tells), enforced by
  regex plus the Luhn-with-80840 test in `vocab/synthetic-identifiers.ts` (layer-neutral, no
  Zod, safe for the app).
- **One fictional city, no state**: `locality.regionText` says how artifacts print the
  region; a real state is never named (the registry README documents the postal `000NN`
  pattern).
- **`@medrecsim/schema` as an app devDependency** (not dependency) so `REVIEW_MODEL` can be
  imported from `@medrecsim/schema/vocab` without `zod` appearing in the notices generator's
  production closure; ESLint still refuses `zod` from the app; bundle-manifest unchanged.
- **Tokens as plain CSS custom properties; contrast as a test** (ADR-8). No theme toggle in
  v1; OS preference rules.
- **Fonts under `packages/app/src/assets/fonts/`** (hashed by Vite, relative URLs) rather
  than `public/` so the build rewrites paths under the `./` base; Latin subset only; italic
  not shipped.
- **Focus ring contrast is measured against the ground**, not the control fill, because the
  ring is offset 2 px (the test comment records this).
- **Asset hygiene dispatches on file content** (PNG/JPEG/WebP signatures; SVG by extension)
  and keeps colour profiles, titles, descriptions and ids; the pre-commit layer checks the
  working-tree file for each staged asset path and fails closed without Node.
- **Universe placeholders now warn as "not screened"** and are excluded from compile unless
  `--include-drafts` (message text changed; no placeholder remains in the seed).
- **`.gitignore` negations for the two design-token files** (`!…/styles/tokens.css`,
  `!…/styles/tokens.test.ts`) placed directly under the `*token*` secrets pattern with a
  comment. Chosen over renaming because "design tokens" is the term every document uses and
  the negation is explicit, path-exact, and reviewable; the pattern still ignores every
  other path containing "token". The EP-0 precedent is the `.vscode/` un-ignore.
- **Pre-commit tripwire skips binary extensions** (fonts, rasters) in layer 2c: `git show`
  of a binary blob produced null-byte warnings and the text patterns cannot match binaries;
  image metadata is layer 2d's job.
- **Exemplar re-pointed** to the real registry ids (`inst-corrowell-general`,
  `inst-quillbrook-pharmacy`, `inst-tessary-family-medicine`); its clinical strings are still
  placeholders (EP-14).

## Risks / notes for the next session

- **`.gitignore` `*token*` bites silently.** Any new file whose path contains "token"
  (a `tokenizer.ts`, a `token-colours.md`) is dropped from `git add -A` without a message and
  every local check still passes. Before the first push of an EP, diff `git ls-files` against
  the intended file list, or run `git status --ignored -- <new dirs>`; if a path is
  legitimately named, add an explicit negation beside the pattern as EP-10 did.
- **Epic composition is recorded from public text only** (decision 4). EP-15 should re-run
  §2.1 with the owner viewing public screenshots in a browser and append to the §7 log.
- **Fonts are Latin-only.** C06 (Spanish-preferring patient) needs only Latin-1 characters,
  which the subset covers (U+00C0–U+00FF); if a case ever needs another script, ship a second
  subset (README explains how).
- **`check:assets` currently scans zero files** (no images in the tree yet); its behaviour is
  proven by the fixture test and the scratchpad demo. The first real image (EP-19 screenshots)
  is where it starts to bite.
- **The banner's `<h2>` precedes the page `<h1>`** (unchanged from EP-8). COMPONENT-SPECS §1
  lets EP-15 lower the level; keep it a heading.
- **No coined UI labels exist yet** — EP-15 appends the first to ORIGINALITY-CHECKLIST §3.
- **Icons**: none yet; §5 policy prefers original inline SVGs — EP-15 decides whether a set
  is needed (dependency-policy checklist if so).
- **`REFERENCE_ID_PREFIXES` unchanged**; registry ids (`inst-`, `person-`) are shared-package
  ids and may appear in evidence text.
