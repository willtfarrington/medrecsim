## The API seam as landed (required by the brief)

```ts
createSession({ case: CompiledCase, appVersion: string, log?: readonly LearnerAction[] }): Session
interface Session {
  readonly caseId: string;
  getState(): SessionState;                 // the fold; JSON data, no reference content
  getView(): SessionView;                   // evidence projection; cached per state
  getLog(): readonly LearnerAction[];       // copy of the append-only log
  dispatch(action: LearnerAction): Result<SessionState>;   // never throws; typed EngineError
  canSign(): SignatureCheck;                // EP-11: {ready:false, blocking:[signature-validation-not-implemented]}
  sign(): Result<SessionState>;             // EP-11: fails 'not-implemented' (or 'session-signed')
  getDebrief(): DebriefResult;              // EP-11: {available:false, reason:'not-signed'|'not-implemented'}
  serialize(): SessionEnvelope;             // the log in the five-field envelope
  subscribe(listener: () => void): () => void;             // notified after each accepted action / signature
}
restoreSession({ case, appVersion, envelope: unknown }):
  { kind: 'restored', session } | { kind: 'discarded', reason: 'malformed'|'mismatch'|'corrupt-log', mismatch, message }
loadCompiledCase(chunk: unknown): CompiledCase   // throws CaseLoadError (6 codes)
createPersistenceAdapter(storage: StorageLike | null, namespace = 'medrecsim:'): PersistenceAdapter
```

(OQ-6 bulk-cite), `discrepancy/set`, `discrepancy/remove`, `action-list/set`,

## Schema friction discovered (feeds the post-EP-19 re-plan; changes go through EP-9's package)

1. **No case-local time zone in the evidence layer.** Windows are authored as local `HH:MM`
   + weekdays; compile resolves every instant to UTC and discarded the offset. EP-11's fix is
   in the **compile output**, not the schema: `compile` writes `caseLocalUtcOffsetMinutes`
   (derived from the offset the author wrote on `T0`) beside `compiledFrom` in each chunk;
   the loader refuses a chunk without it. An explicit `locale`/offset field in `evidence.yaml`
   would make the intent visible to authors (AUTHORING.md §4a tells them for now).
2. **`AllergyClaim` has no `visibility`** (`Claim` does). The engine infers on-reveal for any
   allergy claim named by a reveal wiring, with-source otherwise. An additive `visibility`
   field on allergy claims would remove the inference.
3. **No authored timed-event primitive.** The levodopa-class clock case (R2) needs an
   evidence-layer event such as "the nurse notes the next dose is due at T0+2h" that fires on
   crossing and may reveal a claim. EP-11 built the generic crossing mechanism
   (`ScheduledEvent`/`FiredEvent`, timeline) so an additive `timedEvents[]` on the evidence
   document slots in as one more event kind.
4. **The rationale menu lives in `reference.yaml` but is learner-facing** (D-MED-004, T-5). The
   engine copies it across the seam as `{key, text}` pairs (ADR-9 decision 6). A
   learner-facing section of the bundle (or a `learnerMenus` document) would make the
   two-layer story cleaner and let INV-TRUTH-001 stop special-casing `rat-`.
5. **`DialogueNode` is not exported as a type** from the schema (only the Zod value); the
   engine derives `DialogueTree['nodes'][number]`. A one-line type export would help.

None of these blocks EP-12 or EP-14; none was worked around ad hoc in the schema package.

## Decisions logged (reversible technical, D-EXEC-003)

- **Compile output carries `caseLocalUtcOffsetMinutes`** (derived from the authored T0's
  offset); the loader requires it. Not a schema change; recorded as friction item 1.
- **Schema package export map** gains `./reference`, `./documents`, `./version` so the engine
  can import narrow, zod-free values (`SCHEMA_MAJOR`, `SCHEMA_VERSION`) and types without the
  root barrel. Schema sources untouched.
- **Engine core boundary by composite project + `paths`** (ADR-9 decision 5): resolving the
  schema through node_modules would make its files "external" and skip the TS6307 check, so
  the evidence project maps every `@medrecsim/schema` entry point to the sources.
- **Three engine tsconfigs**: `tsconfig.json` (src only, `types: []` — the platform-free
  guarantee), `tsconfig.evidence.json` (the seam boundary), `tsconfig.test.json` (tests +
  test support with node types). `pnpm typecheck` runs all three.
- **Fixture bundle compiled at test time** from `content/cases/_exemplar` through the content
  CLI (`test-support/exemplar.ts`), never hand-copied — the fixture cannot drift from the
  schema. Cost: `@medrecsim/content-tools` as an engine devDependency (tests only; the lint
  fence refuses it from sources).
- **Workspace keys renamed** `discrepancyLog` / `actionList` (not `discrepancies` /
  `actions`) so no learner artifact shares a key name with a reference-layer section; the
  runtime leak check relies on this.
- **`getLog` and `subscribe` added to the seam**; `history/seed-from-source` (OQ-6) and
  `await-escalation` added to the vocabulary; `sign` refused via `dispatch`.
- **Escalation initiation costs 0 minutes**; latency is a threshold event the learner awaits
  explicitly. EP-21 may add an authored call cost (additive).
- **A node or artifact is asked/examined once**; repeats are typed errors rather than silent
  no-ops so the log stays meaningful for the debrief.
- **`ENGINE_STATE_VERSION = 1`**; bumping it discards stored sessions (I-4).
- **Allergy-claim visibility inferred from reveal wiring** (friction item 2).
- **`sort()` without a comparator is a lint error in engine sources** (determinism of
  ordering, not just of values).

## Risks / notes for the next session

- **Restore-time cost is linear in the log** (a fold on every restore). Fine at C01 scale
  (dozens of actions); if a case ever needs hundreds, snapshotting is an additive change.
- **`pnpm typecheck` for the engine runs three `tsc` projects** (~3 s each locally). If CI
  time matters, the evidence project could move under `check:layers` only.
- **The app bundle grew by 864 B gz** from the engine barrel's constants although the app
  uses none of them yet; EP-15 should import from the seam and let Vite tree-shake, and the
  budget check will show the real engine cost then.
- **`REFERENCE_ID_PREFIXES` now has one sanctioned exception (`rat-`) at the seam**, encoded
  in `view.test.ts`. If the menu moves (friction item 4), delete the exception.
- **Windows evaluated with a fixed per-case offset**; a case that authors a DST transition
  inside its span would drift by an hour — no v1 case spans a day.
- **EP-12 owns `canSign`**: nothing in EP-11 lets a learner sign, so EP-17 (interview UI)
  can proceed against the seam without a signature path.
