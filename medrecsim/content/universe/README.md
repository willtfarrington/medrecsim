# content/universe

The fictional-universe registry (integrator resolution I-9): the shared content package beside
the formulary that names the fictional hospital, pharmacies, prescriber offices, programs and
recurring people. Cases reference entries by id (`inst-…`, `person-…`) so names live in one
place for the trade-dress originality checklist (D-UX-001, EP-10). Placeholders here are
replaced when EP-10 coins the real fictional names. CC BY 4.0.
