# tests/e2e

Playwright keyboard-only end-to-end smoke tests and `@axe-core/playwright` checks (D-QA-001,
D-UX-004). Runs on Ubuntu for every pull request and on Windows nightly (I-5). Arrives with
EP-15 (smoke) and EP-18 (workspace flows); the CI slot is reserved in `.github/workflows/ci.yml`.

Empty at EP-8 by design.
