# Support

medrecsim is a personal, single-maintainer project. Support is **best-effort with no
service-level commitment**: there is no guaranteed response time, no support contract, and no
obligation to act on any request.

## Where to ask

**GitHub Issues only.** Discussions, wiki, and project boards are intentionally disabled.
Please pick the matching template when you open an issue:

- **Bug report** for something that does not work as described.
- **Accessibility issue** for a barrier affecting keyboard, screen-reader, zoom, motion, or
  contrast.
- **Clinical content concern** for a contested classification, action set, teaching note, or
  citation in a case.
- **Feature request** for ideas. Scope is frozen during construction; ideas are recorded in the
  roadmap's parked list, not promised.

## What not to send

- **Security vulnerabilities**: use the private reporting flow in [SECURITY.md](SECURITY.md),
  never a public issue.
- **Any real patient information**, including "de-identified" anecdotes, screenshots of real
  systems, or institutional documents. Issues containing such material will be deleted and, if
  necessary, the repository history cleaned.
- **Requests for medical advice.** This is an educational simulation and cannot answer
  clinical questions about real people.

## What to expect

Issues are read and triaged when the maintainer has time. A closed issue with a pointer to the
parked list or to a decision in [DECISIONS.md](DECISIONS.md) is a normal outcome, not a
dismissal. If the project ever enters a reduced-maintenance state, the README will say so.
